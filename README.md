## 📱 Mobile × Backend

Une de mes forces est de pouvoir comprendre les deux côtés d'une application.

```text
                    PRODUCT
                       │
          ┌────────────┴────────────┐
          │                         │
          ▼                         ▼
       MOBILE                    BACKEND
          │                         │
          │       REST / API        │
          └────────────┬────────────┘
                       │
                       ▼
                    DATA
```

Cela permet de mieux comprendre les contraintes liées à la communication entre le client, l'API et les données.
